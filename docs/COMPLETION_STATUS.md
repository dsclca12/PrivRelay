## 2026-10-22 可靠性与产品补齐

- 后端模型请求移出全局锁，在途撤销、配置变化和并发恢复不会被旧结果覆盖；后台重试轮转，WebSocket 独立写入，SIGTERM 等待在途 HTTP 和后台分类结束。
- 增加 OS 级单实例文件锁，防止两个服务或离线维护工具同时打开同一个库；增加校验清单、加密备份、恢复及输出到新目录的换钥命令。
- Web / Android 支持消息归档和取消归档，沿用消息修订同步；隔离箱不会因归档隐藏消息。Android 队列保留未同步的归档意图。
- Android 增加设备密码应用锁，后台收信同步继续运行；启用时强制开启防截屏。
- Web 支持授权导出已审核纠错样本，默认不包含正文；用途、正文授权、设备、时间与数量写入加密审计记录，不自动训练。
- 本机 Flutter 从 3.47.2 升至当前稳定版 3.47.7 / Dart 3.13.5；项目显式声明最低 Flutter 版本，Node 22 写入 `.nvmrc`。
- 增加跨平台验证和 APK / AAB 发布脚本、Caddy HTTPS 配置、CI Debug APK 产物，以及容器内上游 POSIX 测试。

本轮证据及边界见 [2026-10-22 验证记录](HARDENING_TEST_REPORT.md)。

## 仍需完成

按投入实际使用的优先级排列：

1. **Android 扩展运行验收**：已在 Android 15 真机通过合成 E2EE 链路；仍需 Android 7/10/12/14、真实双卡运营商来信、断网 30 分钟、Doze、低电量、设备重启、后台进程回收和消息最终补发检查。真机短信发送未执行，以免产生运营商费用。
2. **真实模型与策略验收**：使用有代表性且经授权的独立数据，测量营销召回、正常／验证码／交易误隔离、不确定比例与端到端 P95。当前模型的校准／复核保护继续保留。
3. **生产部署与发布**：先前 Docker Compose、卷内备份恢复／换钥和本地 TLS 代理的实测范围见[可靠性报告](HARDENING_TEST_REPORT.md)；公网证书签发、长期运行、真实断电／磁盘故障及生产压力仍需验收。本次合并后的 CI 与本地结果见[并行审计](AUDIT_2026-10-22.md)，正式签名需要运营者私钥。
4. **Android 默认短信角色**：默认角色申请、SMS_DELIVER 写系统 Provider、MMS 下载后的文本与附件导入、`SENDTO` composer、快捷回复服务已接入。附件在本机 SQLCipher 消息记录和 E2EE envelope 中保存；每条 MMS 有 2 MiB 附件上限，超限部分保留系统 Provider 并提示。历史导入当前只覆盖 SMS。单条 SMS 发送有应用内确认与 carrier fee 提示。主要静态 UI 文案可切换英文；动态模型原因可能保留原语言。
5. **架构扩展**：新增 PostgreSQL 加密 tenant snapshot、每租户 HKDF 密钥派生、跨主机 advisory lock 和保留旧快照的迁移入口；每个服务实例绑定一个 tenant ID。设备级 admin/editor/viewer 权限可按配对码指定及后续调整，保护最后一个管理员。数据格式仍是整租户加密快照而非关系表，尚无同租户水平多实例或独立用户/组账户；维护/换钥工具仍仅支持文件后端。端到端加密已实现独立密文协议，仍需独立安全审计、口令恢复和迁移验收；它不能与服务端读取正文的分类功能同时使用。
6. **反馈后续用途**：新增单条反馈授权撤回 tombstone，阻止后续审核与导出；分类器新增明确授权的本地训练导出导入工具，校验用途、文本和类别、去除发送方及消息 ID、去重并标记 human-verified/training-only，不会自动训练或上传。撤回不能远程删除已下载文件或备份。服务端 E2EE 密文保留期限与同步删除墓碑已实现并默认关闭；旧明文遗留、备份及离线客户端副本清理未覆盖。

项目当前仍应标记为可联调的 MVP，而非已经完成生产稳定性与全部立项验收。
