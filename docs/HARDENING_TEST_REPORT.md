## 发布与外部验收边界

- Release 使用 Dart 混淆与单独符号，但构建工具仍提示 ELF 含未混淆的 DWARF 调试信息；尚未验证全部原生符号剥离，不将产物描述为完全无调试信息。开发签名产物仅供内部验收。
- 构建环境仍提示 Gradle 8.14.1、AGP 8.13.1、Kotlin 2.2.20 后续需要迁移；本轮构建与测试通过不等于已迁移至 AGP 9。Android 设备密码 API 存在弃用提示，当前 minSdk 24 兼容路径已编译，原生交互需真机确认。
- 没有连接 ADB 手机。本轮不宣称验证过真实双卡运营商来信、Doze、整机重启、30 分钟断网、OEM 后台稳定性或原生密码交互。
- 没有代表性的授权真实短信集；没有重新训练模型、测量真实误隔离率或验证外部 LLM 提供商。
- 没有提供生产域名或签名私钥；公网证书签发／续期、正式签名发布、GitHub Actions 远端执行结果仍需外部条件。
- 长时间运行、真实断电／介质故障及生产压力尚未验收。代码已有写盘失败和篡改故障测试，不能替代真实硬件验收。
- 英文 ARB、前台常驻服务、服务端保留期限／跨设备删除、多用户／数据库迁移／多实例／端到端加密未实现；它们仍是独立后续工作。项目级许可证保持待作者决定。
